# Arch Linux 安装脚本

##  简述
通过观察，我发现 `archinstall` 脚本过于复杂，然而更多人不愿意手动安装 Arch Linux
对于那些拥有一些分区能力的用户，我编写了一个脚本. 这个项目使用 bash 编写，能够快速的部署 Arch Linux，帮助这些人部署 Arch Linux

##  语言问题
考虑到 Arch Live 的 tty 无法显示中文的问题，我使用了一些信息技术工具将脚本翻译为了英文，方便随时查看

##  免责声明
使用此脚本造成的损失由个人承担，与开发者无关. 如果认为此脚本对你的设备有威胁，你可以随时查看源码

##  注意事项
此脚本适合在 Arch Live 环境中运行，不推荐在其他环境运行，否则可能会造成不可逆损失
